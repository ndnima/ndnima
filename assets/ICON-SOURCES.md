# Icon and banner sources

Brand icon capsules are stored directly under `assets/light/` and `assets/dark/` (no nested `icons/` folders). The updated capsules use a simple circular logo inset, restrained two-tone neon accents, and a compact label, matching the reference contact-pill style.

- Python, Ollama, LM Studio, LangChain, n8n, Hugging Face, Linux, Android, Docker, Godot Engine, Unity, Blender, Git, GitHub, Vim, YouTube, Telegram, Instagram, Gmail, and ORCID iD: [Simple Icons](https://github.com/simple-icons/simple-icons).
- Termux: [Termux.svg on Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Termux.svg), sourced from Termux.com.
- llama.cpp: official [ggml-org/llama.brand](https://github.com/ggml-org/llama.brand) icon assets.
- VS Code and LinkedIn: [Devicon](https://github.com/devicons/devicon).
- Portfolio: custom briefcase pictogram drawn for this README.
- The theme-specific animated hero banners, currently-exploring focus animations, and shared neon star-footer animation are custom artwork.

Brand marks remain the property of their respective owners. The capsule/button styling is an original presentation wrapper around the cited logo artwork.
